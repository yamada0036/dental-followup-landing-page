# Praxora P0 Funnel Configuration Notes

The site no longer uses a Tally placeholder form.

Before sending real traffic, configure the Vercel environment variables listed in `.env.example`, run `docs/supabase-schema.sql` in Supabase, and verify the Resend sending domain.

Required production checks:

1. Supabase tables `leads` and `leak_reviews` exist.
2. `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` are configured server-side in Vercel.
3. `RESEND_API_KEY`, `PRAXORA_FROM_EMAIL`, and `PRAXORA_NOTIFICATION_EMAIL` are configured server-side in Vercel.
4. `PRAXORA_GA_MEASUREMENT_ID` is configured if GA4 tracking should collect real events.
5. Vercel Production is redeployed from the intended main branch commit.

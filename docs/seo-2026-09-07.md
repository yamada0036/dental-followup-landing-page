# Dental follow-up SEO maintenance — 2026-09-07

## What was observed

- Production homepage and repository main matched the same headline and metadata. The site is static HTML with Vercel API endpoints, not a client-only application.
- Production robots.txt and sitemap.xml returned HTTP 200. The canonical host already consistently used dental-followup-landing-page.vercel.app.
- Both / and /index.html were accessible; homepage links frequently used the latter despite the former being canonical.
- Homepage Resources navigation pointed at the homepage excerpt, rather than the complete resources hub.
- No page contained JSON-LD. Existing article content, canonical tags, and the intentional Recovery Kit noindex were present.
- Shared reveal CSS hid content by default. JavaScript and intersection callbacks were necessary to display it.

## Changes

- Homepage title/H1 now explicitly describe AI dental patient follow-up. Calculator and resource-hub titles clarify the tool and guide search intents.
- Added three visible, native HTML FAQ disclosures to answer basic operational questions and connect visitors with existing workflow guides and conversion pages.
- Added Organization/WebSite/WebPage schema on the homepage, page schema throughout, and Article plus BreadcrumbList schema on all 12 article pages. Breadcrumbs are also visible. No fabricated ratings, pricing, customer results, dates or author identities were added.
- Completed consistent Open Graph/Twitter metadata using the existing image asset.
- Linked the full resources hub from navigation, used descriptive homepage article links, and linked the existing implant workflow example from the hub.
- Normalized home links to / and added a permanent Vercel /index.html → / redirect. Existing article URLs and their self-canonicals remain in place.
- Made reveal content visible by default. Only eligible below-viewport elements are hidden for animation after the observer is installed; hero and complete article wrappers remain visible. Reduced-motion users receive visible content.
- Updated sitemap lastmod for the edited pages. Recovery Kit remains noindex and excluded from the sitemap.

## Validation

Run `python3 scripts/check_seo.py` and `node --check script.js`.

The dependency-free SEO check passed for 18 pages, 12 Article/BreadcrumbList graphs, 17 sitemap URLs and 420 internal links. It checks unique metadata, canonicals, JSON parsing, local assets, fragment targets, sitemap/indexability alignment and the preserved Google verification file.

This is static/source validation. It does not constitute a Lighthouse measurement, browser visual test, Google Rich Results Test, ranking measurement, or proof of Google indexing. No production forms or API submissions were exercised.

API handlers, calculator formulas, Supabase, email configuration and GA event logic were not changed. Search Console data was unavailable, so traffic bottlenecks and ranking gains are not asserted.
